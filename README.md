# 🎨 PCB透光画图层生成器

一个专业的PCB透光画设计工具，将彩色图像转换为PCB制版所需的各层Gerber文件。

## ✨ 功能特性

- 🎨 **多色系支持** - 蓝色系、红色系、紫色系三种主题
- 🔧 **智能颜色简化** - 将复杂图像简化为6种标准颜色
- 📏 **自适应缩放** - 可根据需要调整图像尺寸
- 🖼️ **图层自动生成** - 一键生成5个PCB图层 + 预览图
- 📝 **详细说明文件** - 自动生成详细的图层说明
- 🔒 **英文文件名** - 避免编码问题，兼容所有系统
- 📍 **对齐标记** - 自动添加四角对齐标记

## 🚀 快速开始

### 基础用法
```bash
# 生成蓝色系PCB图层
python main.py origin.png

# 生成红色系PCB图层
python main.py origin.png -c red

# 生成紫色系PCB图层
python main.py origin.png -c purple
```

### 完整参数
```bash
python main.py origin.png \
  -c blue          # 色系：blue, red, purple
  -s 0.25          # 缩放倍数：0.1-1.0
  -t 15           # 颜色容差：1-100
  -o my_pcb       # 输出目录
  --no-preview    # 不生成预览图
```

## ⚙️ 参数详解

| 参数 | 说明 | 默认值 | 示例 |
|------|------|--------|------|
| `input` | 输入图像路径（必填） | - | `origin.png` |
| `-c, --color` | 色系选择 | `blue` | `red`, `purple` |
| `-s, --scale` | 图像缩放倍数 | `1.0` | `0.25`, `0.5` |
| `-t, --tolerance` | 颜色匹配容差 | `10` | `5`, `20` |
| `-o, --output` | 输出目录 | 自动生成 | `my_output` |
| `--no-preview` | 不生成预览图 | 生成 | - |

## 🏗️ PCB图层说明

### 1. **顶层丝印层** (`top_silkscreen.png`)
- **对应**：白色区域
- **PCB层**：Top Silkscreen
- **用途**：PCB表面的文字和图案标记

### 2. **顶层阻焊层** (`top_solder_mask.png`)
- **包含**：黑色、深绿色、黄色区域
- **PCB层**：Top Solder Mask
- **逻辑**：**负片** - 白色区域表示开窗（无阻焊）
- **用途**：控制顶层哪些区域裸露铜皮

### 3. **顶层铜皮层** (`top_copper.png`)
- **包含**：浅蓝色、黑色区域
- **PCB层**：Top Copper
- **逻辑**：**正片** - 白色区域表示有铜皮
- **用途**：定义顶层的铜皮走线

### 4. **底层阻焊层** (`bottom_solder_mask.png`)
- **包含**：深蓝色、浅蓝色、黑色、黄色区域
- **PCB层**：Bottom Solder Mask
- **逻辑**：**负片** - 白色区域表示开窗（无阻焊）
- **用途**：控制底层哪些区域裸露铜皮

### 5. **底层铜皮层** (`bottom_copper.png`)
- **包含**：深绿色区域
- **PCB层**：Bottom Copper
- **逻辑**：**正片** - 白色区域表示有铜皮
- **用途**：定义底层的铜皮走线

## 🔄 透光画原理

PCB透光画利用PCB的多层结构和材料的透光性实现：

1. **基板** - FR4环氧树脂板，自然黄色
2. **阻焊层** - 蓝色/红色/紫色阻焊油墨
3. **铜皮层** - 铜箔，反光不透明
4. **丝印层** - 白色油墨，不透明

### 透光机制：
- **黄色区域**：前后都无阻焊无铜皮 → 透出基板黄色
- **绿色区域**：顶层透光，底层绿色阻焊+铜皮 → 绿色
- **蓝色区域**：顶层蓝色阻焊，底层透光 → 蓝色
- **黑色区域**：顶层露铜，底层透光 → 不透光

## 💡 使用技巧

### 1. **图像准备**
- 建议使用清晰的PNG图像
- 图像中尽量包含6种定义的颜色
- 复杂的图像可能需要调整容差值

### 2. **参数调整**
- **缩放倍数**：大图像使用0.25-0.5倍缩放提高处理速度
- **颜色容差**：颜色匹配不准时适当增加容差值
- **色系选择**：根据设计需求选择合适的色系

### 3. **PCB制版**
1. 将生成的PNG文件上传到PCB制版网站（如嘉立创）
2. 按照README文件中的对应关系选择正确的层
3. 特别注意阻焊层是负片逻辑
4. 确认无误后提交制版

### 4. **故障排除**
```
问题：生成的图层空白
解决：检查输入图像是否包含定义的颜色，调整容差值

问题：文件保存失败
解决：检查文件写入权限，尝试使用英文路径

问题：颜色匹配不准确
解决：减小缩放倍数，增加颜色容差
```
